## ✨ ویژگی‌ها

- **طراحی Ultra-Luxury** با تم Black & Gold
- **احراز هویت** با رمز ثابت `reza grootz`
- **مدیریت کامل** کانفیگ‌ها (VLESS / Reality / Trojan / StormDNS)
- **سیستم کاربران** با نقش‌های admin/user
- **لاگ‌گیری پیشرفته** و داشبورد تحلیلی
- **تولید لینک** و کد base64 برای کانفیگ‌ها
- **سازگار با Railway** و Docker
